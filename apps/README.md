# Mobile Apps Directory

Simpan file `.apk` (Android) atau `.ipa` / `.app` (iOS) di folder ini.

## File APK Sample Gratis untuk Belajar & Testing:
Kami menggunakan **Sauce Labs My Demo App** (E-Commerce React Native Demo):

1. Buka halaman release resmi GitHub:
   👉 https://github.com/saucelabs/my-demo-app-rn/releases
2. Download file: `Android-MyDemoAppRN.<version>.apk`
3. Rename file tersebut menjadi:
   `my-demo-app.apk`
4. Letakkan di folder ini (`apps/my-demo-app.apk`).

## Testing di Android Emulator:
Pastikan emulator Android sudah berjalan sebelum menjalankan command:
```bash
npm run test:android
```
